# Docs

Deep dives on how and why this site is built the way it is, written up as I learn each piece — not a formal spec, just notes for the curious (mostly future me).

Start here:

- [architecture.md](./architecture.md) — the stack, content collections, and how a page gets built
- [deployment.md](./deployment.md) — how a push to `main` becomes a live page, and why there are two deploy workflows
- [dns-and-cloudflare.md](./dns-and-cloudflare.md) — how DNS, GitHub Pages, and Cloudflare fit together (and don't)
- [analytics.md](./analytics.md) — the analytics tools that have come and gone, and why
- [content-and-cms.md](./content-and-cms.md) — posts, field notes, and editing through Pages CMS
- [reading-page-sync.md](./reading-page-sync.md) — the `/reading` page, its Goodreads RSS scrape, and the weekly sync that keeps it current
- [photos-migration.md](./photos-migration.md) — why photo galleries left this repo

`README.md` at the repo root stays a quick-start; `AGENTS.md` stays a terse reference for coding agents. This folder is the place for the longer story.
